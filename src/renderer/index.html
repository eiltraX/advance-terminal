SSH KEY CENTER

SSH Keys

How to connect with SSH keys
  1. Generate or select a private key below.
  2. Click Copy Public Key.
  3. Open your hosting control panel and find SSH Access, SSH Keys, or Authorized Keys.
  4. Add/import the copied public key, then enable SSH access for the hosting account.
  5. Go to Manage Connections and select the private key from the dropdown.
Security rule

Only copy the public key ending with .pub. Never copy, upload, or share the private key.

START HERE

Quick Start

  1. Open and generate or select your SSH key.
  2. Copy the public key and add it to your hosting account or server authorized_keys.
  3. Open and add your SSH server, username, port, auth type, and start folder.
  4. Click Connect in the left panel. The terminal should open directly inside the configured start folder.
  5. Use to keep safe paste, right-click behavior, and SSH folder lock under control.
  6. Use to summarize the project work shown by the current terminal session.

SAFETY

Terminal Safety Guide

  • controls paste and SSH folder protection.
  • Confirm before multi-line paste stops accidental execution of pasted command blocks.
  • Right-click paste then Enter is useful for fast work but should stay off unless you need it.
  • Lock SSH terminal to start folder blocks obvious cd /, cd ~, nested SSH/SFTP jumps, and navigation outside the configured project folder.
  • This is a safety guard, not server security. Real access limits still come from the SSH user, hosting permissions, and server configuration.
RECOVERY

Restore, Repair, Import & Export

  • shows local settings restore points with date, file name, connection count, and preview.
  • restores missing connections only from valid readable backups.
  • saves a safe backup of your app configuration.
  • imports a backup after previewing it.
  • Auto-backup runs at startup, before/after settings saves, and on normal close. Force close or power loss cannot always run close handlers, so startup/save backups are important.
  • Exports skip passwords, passphrases, private keys, report history, and usage data.
OPENAI

AI Report Guide

  • Open to enable AI reports, save the OpenAI API key, and choose the model.
  • Open a local project terminal or SSH terminal, then use .
