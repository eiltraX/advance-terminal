# Code Signing Policy

Advance Terminal is maintained by **Artlie Digital**.

**Free code signing provided by SignPath.io, certificate by SignPath Foundation.**

## Team Roles

### Committers and Reviewers

- **eiltraX / Artlie Digital**
- External contributions must be reviewed before they are merged into the official repository.

### Approvers

- **eiltraX / Artlie Digital**
- Every release signing request must be manually approved by an authorized approver before an official signed build is published.

## Build and Release Policy

Official signed Advance Terminal binaries must be built from the public Advance Terminal source repository using the approved trusted build system.

Only release artifacts produced from the official repository and approved release workflow may be submitted for code signing.

Modified, third-party, or locally produced builds are not official Artlie Digital releases unless explicitly designated as such by Artlie Digital.

## Privacy Policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Advance Terminal may connect to networked systems when the user explicitly performs an action that requires network access, such as opening an SSH connection, checking for updates, downloading an update, or using another user-configured network feature.
