# Advance Terminal v7.1.0

Source release candidate based on v7.0.1.

## Changes
- One-click reconnection for disconnected saved sessions
- Unified Appearance and Settings interface
- Neutral charcoal Settings styling
- Improved session tree drag-and-drop
- Multiline command composer and safe paste behavior
- Terminal resizing and PowerShell prompt fixes
- Save reliability and UI performance improvements
- Security and navigation regression checks

## Validation
Local source regression checks and Windows x64 NSIS build passed.

Installed-app testing and Electron security upgrade remain pending.

The Windows installer is not included in this source branch.
